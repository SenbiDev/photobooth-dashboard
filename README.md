# Lil Photobooth / Edge Console

Front-end dashboard untuk mengelola runtime configuration dan kesehatan fleet edge Our Lil Photobooth. Dibangun dengan Next.js App Router, TypeScript, Tailwind CSS, dan Lucide icons.

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Catatan implementasi

Versi ini sengaja front-end only dengan mock data lokal. Alur yang sudah tersedia untuk dihubungkan ke backend: device/event selection, runtime config, draft revision, toggle operational controls, publish revision, activity/audit trail, dan health/queue overview.
